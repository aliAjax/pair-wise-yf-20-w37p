# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62008

## 业务文件结构（判定 / 存储 / 页面 三分离）

- `src/lib/schedule.ts` —— **判定层（纯逻辑）**：预置三段节目（序幕 0–31 拍 / 中篇 32–63 拍 / 终章 64–120 拍）、四个点位、0.5 秒一拍共 120 拍的配乐网格；时刻⇄拍号换算、向最近拍点吸附；`validateBatch` 整批校验。
- `src/lib/storage.ts` —— **存储层（只写 localStorage）**：读取/整批追加/删除/清空，首次访问写入 8 条合法预置节点（清空后不再补种）；无任何网络请求。
- `src/pages/OrchestratorPage.tsx` —— **页面层**：配乐时间轴（段落色带、四点位泳道、原始时刻刻度与吸附结果）、点位平面图、实时冲突清单、点火节点登记表、已编排节点表、4× 加速整场预览。
- `src/App.tsx` 仅作壳挂载页面。

## 保存规则（整批事务）

点“保存整批”时，每行时刻先吸附到最近拍点，再统一校验，任一不满足即**整批拒绝、原编排不动**，修正后可原样重提：

1. 目标拍号为网格内整数，时刻可解析（秒数或 `mm:ss.f`）；
2. 吸附后偏离目标拍号 **超过一拍**（恰好 1.0 拍放行）；
3. 吸附时刻落在所属段落闭区间内（越段拒绝）；
4. 同一点位任意两发（含新-新、新-旧）间隔 **不足 1 秒**（恰好 1.0 秒放行）。

冲突清单、时间轴与点位图随表单输入实时同步。
